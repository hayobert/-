# 泡泡星球 — 简介
一款零压力、不内耗的戳泡泡解压小游戏。

# 怎么玩
戳泡泡。就这么简单。

画面里飘着各种泡泡——普通的、彩虹的、巨大的、会唱歌的——你只需要对着屏幕戳戳戳。连戳触发连击，巨型泡能炸掉一圈，音乐泡能弹出旋律。戳就爽了，连击更爽。

但要小心——从第 4 关开始，暗红色带刺的陷阱泡泡会混进来，碰到了会扣命戳。3 条命扣光，这关就得重来。

# 特色
纯直觉操作 — 没有教程，不用学。打开就会玩
6 种泡泡 — 普通 / 彩虹 / 巨型 / 音乐 🎵 / 冰冻 / 压力，每种手感不同
音效是灵魂 — 戳爆有声，连击变调，音乐泡能在你指尖弹出一段旋律
5 大星球 77 关 — 森林 → 海洋 → 宇宙 → 花园 → 梦境，难度递进但不施压
装扮自由搭配 — 泡泡皮肤、粒子特效、背景主题，通关赚星星买
陷阱恰到好处 — 不是来折磨你的，是让你在爽快中多一点点专注的刺激

# 适合谁
通勤地铁上、开会摸鱼时、睡前放空、或者纯粹想找个东西戳一戳——5 分钟一局，随时打开随时爽。
